## ▶️ Execution Guide

### **1️⃣ Navigate to project folder**
```bash
cd AI_Task3
```

### **2️⃣ Install dependencies**
```bash
pip install pygame
```

### **3️⃣ Run the program**
```bash
python musicapp.py
```

### **4️⃣ Use the Application**
1. Load music files or playlist
2. Use control buttons: Play, Pause, Stop
3. Navigate between tracks
4. Adjust volume as needed
5. Manage your music library
